# Working in pdt-pulse

Household Pulse Survey (HPS) metadata built to the PublicDataToolkit standard (`../PublicDataToolkit/STANDARD.md`). To build or improve this repo, follow `../PublicDataToolkit/instructions/`. To search the metadata, read `agent/index.md` first.

- `metadata/releases/`, `metadata/derived/` and `build/report.md` are generated by `build/build_records.py`. Don't edit them; change the build or `build/slice.yaml`.
- `agent/`, `docs/` and `export/` are generated by `make views`. Don't edit them.
- `dataset.yaml`, `sources.yaml`, `EXTENSIONS.md`, `build/slice.yaml` and `metadata/corrections.jsonl` are edited by hand.
- `data/` is gitignored and never committed.
- Run `make build`, `make views`, then `make check`. Read `build/report.md` after every build.
- Terms questions go to a person; don't decide them.
