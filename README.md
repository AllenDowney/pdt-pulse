# pdt-pulse

Metadata for the [Household Pulse Survey (HPS)](https://www.census.gov/programs-surveys/household-pulse-survey.html), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** started from the PublicDataToolkit template; no records yet.

## What the dataset is

The Census Bureau's online survey of US adults on how the COVID-19 pandemic and later events affected households, run every one to two weeks from April 2020 to September 2024, with the questionnaire revised by phase.

## Terms of use

The terms are at https://www.census.gov/about/policies/open-gov.html. They haven't been reviewed yet, so nothing built from this repo may ship (STANDARD.md §8). Once a person has decided them, summarize them here; the decision is in [`dataset.yaml`](dataset.yaml).

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum.

## How to use the metadata

- `metadata/releases/<release>/variables.jsonl`: one record per variable, with where each fact came from.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

How to cite the dataset (from the publisher) and this repo.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make views
make check
```
