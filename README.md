# pdt-pulse

Metadata for the Census Bureau's [Household Pulse Survey (HPS)](https://www.census.gov/programs-surveys/household-pulse-survey.html), built to the [PublicDataToolkit](https://github.com/AllenDowney/PublicDataToolkit) standard.

**Status:** a slice (PublicDataToolkit Task 55): about 25 variables in every one of the survey's 72 cycles, 2020–2024.

## What the dataset is

The Household Pulse Survey is the Census Bureau's online survey of US adults on how the COVID-19 pandemic, and later events, affected households: employment, food sufficiency, housing, health, mental health and more. It ran every week from April 2020 (weeks 1–12), then every two weeks (weeks 13–63, to September 2023), then in two-week cycles in 2024 (cycles 1–9). The questionnaire was revised by phase: 1, 2, 3, 3.1–3.10 and 4.0–4.2.

Each week or cycle has its own public use file, with its own data dictionary, so each is a release here: `week01`–`week63` and `cycle01`–`cycle09`. Each release has two tables: `puf`, the respondents, and `repwgt`, their 80 person replicate weights. The two tables are keyed by `SCRAM`.

The variables are the identifiers, the person and household weights, the replicate weights, demographics (birth year, sex or gender, sexual orientation, Hispanic origin, race, education, marital status, household size, income), the four mental-health items (anxious, worry, interest, down), and food sufficiency. Each is recorded in every cycle whose dictionary has it.

## How to get the data

The files are listed in [`sources.yaml`](sources.yaml), with where to get each and its checksum: every cycle's CSV zip (about 5 GB in all), each phase's user notes, and two Source and Accuracy Statements. All come from www2.census.gov:

```bash
make download ARGS=--accept-terms
```

`make data RELEASES="week01 week02"` writes the common-format files, `data/processed/pulse-<release>-{puf,repwgt}.parquet`, and checks that every cell round-trips. Run it a few releases at a time, under a memory cap.

## How to use the metadata

- `metadata/releases/<release>/{puf,repwgt}/variables.jsonl`: one record per variable per cycle, with its question wording, codes and missing types, and where each fact came from.
- `metadata/links.jsonl`: each variable from one cycle to the next. A link says when the wording or codes changed. Where Census's user notes state a change, the link cites them; for example, the mental-health items' reference period went from 7 days to two weeks at week 34.
- `dataset.yaml`'s `design`: `PWEIGHT` and its 80 replicate weights, PWEIGHT1-80 (successive difference replication). The replicate weights have no records of their own: the design names them, and they're plain columns in each cycle's `repwgt` data file.
- `docs/`: a page per variable, generated by `make views`.
- `agent/`: shards for LLMs; start with `agent/SKILL.md`.

## How to cite

The data: U.S. Census Bureau, Household Pulse Survey, [week or cycle] public use file, https://www.census.gov/programs-surveys/household-pulse-survey/data/datasets.html.

This repo: pdt-pulse, PublicDataToolkit metadata for the Household Pulse Survey.

## How to rebuild

With the sources in `data/raw/` and a PublicDataToolkit checkout next to this repo:

```bash
make build
make data
make views
make check
```
